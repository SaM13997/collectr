Changelog

2026-05-09

Multi-source app foundation shipped

Collectr now supports source-aware saved items for X, Reddit, Instagram, and generic links, while keeping the app organized around folders, tags, notes, and search.

  • Expanded item model with source, canonical URL, metadata, notes, tags, summary, and read state.
  • Added Reddit ingestion, Instagram URL-only support, AI enrichment, export/import, and offline support.
  • Shipped command palette, bulk actions, drag-and-drop reorder, virtualized lists, and optimistic UI updates.
2026-05-09

UI cleanup and landing page refresh

The app copy now reads as a general saved-link organizer instead of an X-only tool, and the unauthenticated experience has a clearer marketing landing page.

  • Removed dead code and heavy decorative shader dependencies.
  • Improved accessibility with larger touch targets, ARIA labels, and better loading skeletons.
  • Added marketing copy, SEO metadata, and a dedicated landing experience.
