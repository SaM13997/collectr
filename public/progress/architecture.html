Codebase Explainer

Architecture, route map, and linking flow for Collectr.

This page is meant for onboarding and maintenance. It explains where the main product pieces live, how data moves from route to backend, and how links are parsed, saved, enriched, and rendered.

High-Level Architecture

Frontend

src/routes holds page-level routes and screen composition.

src/components holds reusable UI, layout, cards, dialogs, and feature widgets.

src/store holds UI-only state with Zustand.

Backend

convex/schema.ts defines the app data model.

convex/items.ts owns item queries and mutations.

convex/folders.ts owns folder hierarchy and counts.

convex/redditSync.ts handles optional Reddit import flow.

Shared Logic

src/lib/url-parser.ts and convex/urlParser.ts normalize incoming links.

src/lib/item-metadata.ts handles source-aware metadata fetching.

src/lib/feature-flags.ts keeps optional integrations gated and safe by default.

Linking Flow

1. Input

Links enter from manual paste, the mobile collect flow, or the PWA share target route at /share-target.

2. Parse

The parser classifies the URL as x, reddit, instagram, or link and produces a canonical URL plus source item id.

3. Persist

The app writes the normalized item into Convex with source metadata, tags, notes, read state, and folder placement.

4. Enrich

Metadata fetch and AI enrichment happen after save when enabled. Failures fall back to a plain link experience instead of blocking the save path.

5. Render

Routes like inbox, folders, search, and entry detail read the same item model and render source-aware UI.

Route Map

/

Landing page when signed out, inbox when signed in.

/collections

All folders and collections.

/folders/$folderId

Single collection view with subfolders and items.

/entries/$entryId

Single item detail view.

/search

Full library search across sources, folders, tags, and text.

/share-target

PWA intake route for links shared from other apps.

/profile

Theme, account settings, integrations, import/export.

  • convex/items.ts for save, move, delete, reorder, and bulk behavior.
