Collectr Visual Uplift

Roadmap, moodboard, and mock system for a slick motion-led brand.

Collectr already has the right product skeleton: a clear data model, a solid TanStack shell, shadcn-style primitives, and motion libraries in the stack. What it lacks is a sharp point of view. The target direction is soft-sage negative space, dark ink structure, loud coral and violet utility cards, capsule controls, poster-like mobile screens, and motion that makes the interface feel intentionally choreographed instead of merely functional.

Current To Target

Move the app from generic utility shell to branded command deck.

Current UI Risk

  • The shell reads as standard muted productivity UI, especially in Sidebar and Header.
  • SavedItemCard and CollectionCard are functional but visually interchangeable.
  • The landing page and signed-in product speak different visual dialects.
  • Motion exists, but it is not yet named, prioritized, or tied to content hierarchy.

Target Product Feel

  • The app opens on a branded command center with urgent tasks, search, and collections in one visual frame.
  • Accent colors map to intent: alert, insight, context, or utility.
  • Marketing, onboarding, and signed-in product use the same token system and shapes.
  • Mobile becomes the visual reference point, with desktop acting like an expanded editorial desk.

Base Stack

Build an internal library on top of the requested component sources.

The goal is not to expose five external design languages inside Collectr. The goal is to absorb the strongest parts of each source and normalize them behind one internal API, one token system, and one motion grammar.

Base kit Role inside Collectr First things to adopt Guardrail
Shadcn Accessibility backbone and primitive control layer. Button, input, sheet, popover, dropdown, tabs, command, separators. Wrap everything so route code imports Collectr primitives, not raw shadcn copies.
Reactbits Micro-interactions and motion-led wrappers. Text reveal, list stagger, magnetic CTA, cursor-aware accents, hover reveals. Use sparingly and tie motion to hierarchy, not decoration.
Aceternity Ambient hero patterns and spotlight moments. Background beams, spotlight cards, animated borders, staged marketing sections. Keep the palette on-brand and avoid generic neon-dark defaults.
Coss UI Operational widgets and dense utility blocks. KPI strips, segmented controls, analytics cards, status chips, data-focused layouts. Retint surfaces and match Collectr spacing, radius, and type before shipping.
Cult UI Editorial brand flavor and launch surfaces. Poster-style hero modules, statement cards, social proof blocks, expressive badges. Do not let marketing blocks diverge from the signed-in product language.

Roadmap

Six-week path from generic UI to branded motion system.

This roadmap is sequenced to minimize churn. Foundations first, shell second, reusable cards third, demo route fourth, polish and rollout last.

Week 1

Freeze The Brand DNA

Turn the reference into tokens, surface rules, motion presets, and content color semantics.

  • Rewrite the design tokens in src/styles.css.
  • Define source-color mapping and chart palette rules.
  • Use this HTML route as the art-direction source of truth.
Week 2

Rebuild The Shell

Give navigation, search, and capture one cohesive command-band language across desktop and mobile.

  • Upgrade AppLayout, Sidebar, and Header.
  • Restyle MobileBottomNav and MobileAddDrawer.
  • Introduce named entrance and drawer motion presets.
Weeks 3-4

Ship The Internal Library

Wrap raw external components and create Collectr-owned cards, filters, tiles, and surfaces.

  • Convert raw primitives into system/primitives.
  • Refactor SavedItemCard and CollectionCard.
  • Create branded empty states, skeletons, and source badges.
Week 5

Launch The Demo Page

Build one internal proving ground where marketing and signed-in product language meet.

  • Create a demo route that shows the home shell, collections, detail view, and command band.
  • Use motion to validate hover, entry, and chart behavior in context.
  • Stress-test the library before broad route migration.
Week 6

Polish And Roll Out

Finish accessibility, performance, and adoption rules so the visual reform holds under real usage.

  • Respect reduced motion and keyboard focus everywhere.
  • Verify core transitions stay smooth on mobile hardware.
  • Block new screens from importing raw third-party blocks directly.

Definition Of Done

The uplift is complete when the product is unmistakably Collectr at first glance.

Unified Language

Landing, onboarding, and signed-in product share the same type, color, motion, and surface rules.

Wrapped Components

No route imports raw third-party building blocks directly. Everything flows through the internal library.

Motion Discipline

Every transition has a named purpose. Nothing bounces for no reason. Reduced motion remains complete.

Mobile Priority

Phone screens look like intentional posters, and desktop feels like a scaled editorial workstation, not a stretched list.
